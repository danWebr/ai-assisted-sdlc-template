# Skill provenance and customizations

`.agents/skills/` is the canonical, dependency-closed project skill source. Pi and Codex discover it directly; Claude Code adapters delegate to it. Do not edit `.claude/skills/` to change workflow behavior.

## Provenance

The bundled engineering workflows are locally modified derivatives of [Matt Pocock's skills repository](https://github.com/mattpocock/skills), which is distributed under the MIT License. The local bundle version is `snapshot-2026-08-22`. Upstream `main` at commit [`5b15a47f2d7150f545fbcacbfe381787fc0230dc`](https://github.com/mattpocock/skills/commit/5b15a47f2d7150f545fbcacbfe381787fc0230dc) is the recorded manual comparison anchor; the local forks are not represented as byte-for-byte copies of that commit.

The upstream MIT notice is preserved in `.agents/skills/LICENSE` and summarized in `THIRD_PARTY_NOTICES.md`. Upstream documentation remains authoritative for the original workflows; this file records the local behavior that differs. Updates are manual: compare against a chosen upstream commit, review every local difference, update the comparison anchor and snapshot version, and never install an automatic template or skill synchronization mechanism.

Cross-skill references are normalized to harness-neutral skill names instead of `/name` commands. Pi users invoke them as `/skill:name`; Codex and Claude Code use their own skill selectors. The `ask-matt` router omits excluded skills and treats initial tracker/domain setup as already complete.

## Pi runtime packages

The skills above depend on Pi runtime capabilities declared in `.pi/settings.json`: `pi-subagents` (roles such as `reviewer`, `scout`, `delegate`, and `researcher`, plus the `subagent` tool contract) and `pi-web-access` (web research). `.pi/settings.json` pins their exact versions so a later clone installs a known-good runtime: `pi-subagents@0.54.0` and `pi-web-access@0.24.1`. These mirror the manual snapshot discipline used for the skill bundle and are intentionally separate — they are runtime capabilities, not copied skills.

## Name-collision caution

Pi keeps the **first** skill discovered when the same skill name appears in more than one location, and to which location wins is a discovery-order function the template does not control. This matters because the canonical names (`code-review`, `tdd`, `ask-matt`, …) are also installed globally on many machines under `~/.agents/skills/` or `~/.pi/agent/skills/`. Before trusting a generated project, confirm either that no global skill shares a bundled name, or that the intended version loads from `.agents/skills/`. Do not rely on project-local copies silently shadowing a global install.
