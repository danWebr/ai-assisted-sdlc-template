# Triage and Wayfinder labels

The five canonical triage roles map directly to these GitHub labels:

| Role | Label | Meaning |
| --- | --- | --- |
| Unreviewed | `needs-triage` | A human or triage agent has not classified the request. |
| More information | `needs-info` | The request cannot advance without reporter input. |
| Agent-ready | `ready-for-agent` | A bounded implementation ticket is ready for explicit human-triggered work. |
| Human review | `ready-for-human` | A specification, decision, or result needs human judgment. |
| Declined | `wontfix` | The request will not be pursued. |

Wayfinder uses `wayfinder:map`, `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, and `wayfinder:task`. GitHub's default labels are preserved.
